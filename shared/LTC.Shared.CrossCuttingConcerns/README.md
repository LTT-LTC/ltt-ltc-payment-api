# LTC.Shared.CrossCuttingConcerns

## Purpose

Provides reusable DTOs, base models, pagination, and helper extensions used across services.

## Responsibilities

- Shared request/response contracts.
- Common pagination/filter abstractions.
- Utility extensions reused by multiple modules.

## When to Change This Project

- You need a reusable primitive for multiple services.
- You want to remove duplicate DTO/helper logic across projects.
